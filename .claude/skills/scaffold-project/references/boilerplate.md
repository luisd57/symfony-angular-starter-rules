# Boilerplate copy manifest

Everything in `boilerplate/` is a real file to copy, not a description to re-derive.
Token list: `tokens.md`.

## Required for the API to boot

Copy these or the shipped PHP does not work:

- `API/config/services.yaml` — binds `RateLimitSubscriber`'s two `RateLimiterFactory`
  arguments (Symfony cannot autowire them) and tags `JwtCreatedListener` /
  `JwtDecodedListener`. Without the file the container fails to compile; without the tags the
  listeners are constructed and never called.
- `API/config/packages/rate_limiter.yaml` — declares the two limiters the above binds to.
- `API/config/packages/lexik_jwt_authentication.yaml` — `{{PROJECT}}_JWT` must match
  `JwtCookieManager.php`.
- `API/config/packages/security.yaml` — firewall ORDER matters; the two single-route
  firewalls must precede the broad public one.
- `API/config/packages/{doctrine,framework,nelmio_cors}.yaml`, `API/config/routes.yaml`.
- `API/phpunit.xml.dist` — the file `tests/bootstrap.php` is referenced from.
- The JWT keypair, generated by `make init` (or
  `php bin/console lexik:jwt:generate-keypair`). Nothing else creates it.

## Copy, then replace tokens

- `API/src/Infrastructure/Security/JwtCookieManager.php` — `{{PROJECT}}_JWT`
- `API/src/Infrastructure/Security/RedisJwtBlocklist.php` — `{{project}}_jwt_revoked_`
- `API/src/Infrastructure/Http/EventSubscriber/RateLimitSubscriber.php` — the `{{FILL}}`
  route list: every login route plus every unauthenticated write route. The limiter is
  selected by route NAME, so renaming a route silently drops its limit.
- `API/.env.example` → `API/.env`, and `API/.env.test`. Generate `APP_SECRET` and
  `JWT_PASSPHRASE`; never keep a `CHANGE_ME`.

## Copy, then extend per domain

- `API/tests/Helper/ApiTestCase.php` — add one `create{Role}AndGetToken()` per role.
- `API/tests/Helper/DomainTestHelper.php` — one factory per entity/state the tests need.
  `reconstitute()` bypasses invariants to reach states only time can produce (expired
  tokens); it is for test helpers only, never handlers or controllers.

## Notes

The interfaces the shipped classes implement (`PasswordHasherInterface`,
`JwtTokenGeneratorInterface`, repository interfaces) belong in `src/Domain/` as driven ports —
create them per `api-architecture.md`. Namespaces assume `App\`.
